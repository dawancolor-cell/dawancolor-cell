# Remaining profile assets

The profile README and vector identity are published. The original portrait JPEG and animated GIF are not yet uploaded because the connected GitHub file-writing tools in this session accept text content only. Upload these two binary files from the design package when available:

- `assets/portrait-original.jpg`
- `assets/type-motion.gif`

Then add the portrait near the top of `README.md` with `![Ishak Dawan](assets/portrait-original.jpg)`. The current profile does not pretend those files are present.
